# EUSD Web Accessibility Training — The 15 Accessibility Checkpoints

A single-page guide to the 15 accessibility checkpoints every EUSD web project must meet — with side-by-side examples, an embedded contrast checker, and how to verify pages using axe DevTools, Lighthouse, and a screen reader.

**Live page:** https://escondido-union-school-district.github.io/eusd-ada-training/

This repository is published via GitHub Pages and contains only the public training page (`index.html`). The page is maintained internally and republished here when it changes.
